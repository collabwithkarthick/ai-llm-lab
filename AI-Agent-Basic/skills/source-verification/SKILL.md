---
name: source-verification
description: Find and cite a web source for a factual conversion factor used in an answer.
---
When the task needs a factual conversion factor:

1. Use `web_search` to find a reputable source for the factor.
2. Check that the result directly states the conversion factor needed for the task.
3. Pass the factor and its source URL to the relevant skill or use them in the final explanation.
4. Cite the source URL in the final answer. If the results do not verify the factor, say so rather than inventing a citation.
